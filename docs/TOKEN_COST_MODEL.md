# 词元成本模型

Agent 回合的 LLM 费用模型：把用户花费与轮次、上下文、输出、缓存命中率联系起来。
行为规则落在系统提示词 `src/coara/prompts/agents/root.md` §词元成本意识，本文档是背后的定量依据。

## 变量

- `s` 系统提示词 token 数
- `i1` 用户输入
- `g_k = o_k + t_k` 第 k 轮模型输出（正文 + 工具调用参数，均按输出计费）
- `r_k` 第 k 轮工具结果
- `n` 总迭代轮次
- 价格（元/百万 token）`p_in` 非命中输入、`p_hit` 缓存命中输入、`p_out` 输出

## 递推与总量

第 j 轮输入

```text
I_j = s + i1 + Σ_{k=1}^{j-1} (g_k + r_k)
```

总输入

```text
Z = Σ I_j = n·(s + i1) + Σ_{k=1}^{n-1} (n−k)·(g_k + r_k)
```

总输出 `G = Σ g_k`

缓存最优近似（前缀全命中，仅最后一轮输入按非命中计费）

```text
C = I_n·p_in + (Z − I_n)·p_hit + G·p_out
  = Z·p_hit + I_n·(p_in − p_hit) + G·p_out
```

均匀假设（g、r 为均值，`Σ(n−k) = n(n−1)/2`）下的核心简化式

```text
Z ≈ n·(s + i1) + (g + r)·n(n−1)/2
C ≈ [n·(s+i1) + (g+r)·n(n−1)/2]·p_hit + [s+i1+(n−1)(g+r)]·(p_in−p_hit) + n·g·p_out
```

第 n+1 轮的边际成本（越往后每轮越贵，历史越长命中费越多）

```text
ΔC ≈ (当时上下文总长)·p_hit + (g+r)·(p_in−p_hit) + g·p_out
```

## 杠杆排序

- **缓存命中率是第一杠杆** deepseek v4flash 命中:非命中 = 0.02:1（1:50），v4pro = 0.025:3（1:120）
  缓存失效（超 TTL / 改前缀 / 换无缓存厂商）则 `p_hit → p_in`，Z 项放大 50–120 倍
- **轮次 n 驱动二次项** `(g+r)·n(n−1)/2` 是历史滚雪球的本体，n 翻倍 Z 约 4 倍
- **g 与 r 被重复计费** 第 k 轮的输出与工具结果在后续每轮输入里重付 (n−k) 次命中费
  单 token 全周期成本：`g_k ≈ p_out + (n−k)·p_hit`，`r_k ≈ (n−k)·p_hit`
- **s 每轮重付** `s·n·p_hit`，且 s 在命中前缀里，稳定前缀才能保住缓存（易变内容放末尾）

## 数值算例（v4flash：0.02 / 1 / 2 元每百万）

取 s=10k，i1=0.5k，g=0.3k，r=2k

| 场景 | Z | 费用 | 对比 |
|---|---|---|---|
| n=10 | 208k | ≈0.041 元 | 基准 |
| n=20 | 647k | ≈0.078 元 | 轮次×2 → 费用×1.9 |
| n=20 且 r=8k | 1787k | ≈0.213 元 | 工具结果×4 → 费用×2.7 |
| n=20 且缓存全丢 | 647k | ≈0.659 元 | 缓存丢失 → 费用×8.5 |

## 对行为的映射

- 降轮次优先：能并行的工具调用同一轮发完，动手前想清楚路径
- 工具结果按需取量：read 带 offset/limit、grep 先定位再精读、命令输出截尾
  但一次取够优于少量多次——欠取导致补轮次（整段历史重输一遍 + 一轮输出费）的代价远大于多取的内容（后续每轮仅按命中价重付）
- 输出即成本：正文精炼、edit 参数只带必要上下文、大文件分步写
- 护缓存：提示词稳定部分在前动态在后，长会话适时压缩历史（一次全价重建换二次增长刹车）
- 省冗余不省质量：验证步骤不砍，一次做对远比返工便宜
