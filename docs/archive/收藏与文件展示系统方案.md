# 收藏改手动点击 + 文件展示系统

> 状态：契约已落地。2026-09-12 手机端文件展示与收藏已打通：收藏键进各文件屏，
> 记录页收藏 Tab 可直达源文件/取消收藏；HTML 默认渲染。

## 已定契约

- 收藏 = 人手点；主体优先文件；无 LLM 代写；无 CLI `/collect` / `/records`
- Web：文件页「收藏」→ `POST /api/records/collect-file`；记录页仍可手点文本收藏
- 手机：`[COARA_COLLECT]` 手点保留；远程工作区文件各屏挂共享收藏键（`CollectActions.kt`）
- `record` 仅 agent；`local_search` 含 `source`；daily = 近 7 天滑动维护、不管文件
- ws.md：目录文件 + 用户行为 + 可选「其它」

## 手机端已落地（2026-09-12）

- 共享收藏键 `RemoteCollectButton`：按收藏库 `source_url` 判定已收藏态，可收藏/取消；
  挂到文本预览屏、图片预览屏、目录浏览行、记录页「最近」行
- 记录页「最近」行点击直达文件预览；收藏条目展开可「打开源文件」（source_url 还原路径）
  或取消收藏
- HTML 文件默认 WebView 渲染（禁 JS/文件/网络访问），标题行眼睛/代码图标切源码
- 文件标题栏去返回箭头，左右边缘滑动返回（复用 `edgeSwipeBack`）；功能行并入标题行
  （视图切换 + 收藏 + ⋮ 菜单）

## 已落地（续）

- `/api/records?scope=user` 列表/详情/删除
- `GET /api/records/file?id=` 收藏文件下载
- RecordsView：**笔记** / **收藏** 分 Tab
