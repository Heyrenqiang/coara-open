# 第 0 章 导读

## 0.1 这本手册讲什么

这本手册从**使用**的角度讲 coara 怎么工作：你输入一句话之后它做了什么、它有哪些能力、这些能力的边界在哪。不讲源码实现，不逐行解释代码——想改代码请去看仓库里的 `AGENTS.md` 和 `docs/COARA_ARCHITECTURE.md`。

读法上不需要从头看到尾。下面按常见需求给出阅读路径，按需取用即可。

## 0.4 阅读约定

- **术语首次出现给一句话解释**，之后直接使用。少数保留英文的专有词：Root（唯一的对话入口）、WDL（工作流描述语言）、YAML/JSON（数据格式）。
- **动作名保留英文**。例如「`orchestrator` 工具的 `run` 动作」指 `orchestrator(action="run")`。
- **路径保留原文**，如 `src/coara/root.py`、`<coara_home>/system/config.yaml`。
- 全书只描述**当前版本**的行为；行为变了就改书，不留历史对照。
