# 第 17 章 远程前端

## 17.1 手机端是什么角色

coara 跑在你的电脑上，但你不总在电脑前。远程前端解决的就是这个问题：**手机上的 coara App 不跑 AI，它只是"遥控"**——你在手机上发的消息经 Matrix 协议送到电脑上正在运行的 Root，Root 的回复再送回手机。思考、工具、文件全部发生在电脑上，手机是窗口。

因为背后是同一个常驻内核，手机端天然拥有和电脑一致的上下文：**上下文按工作空间共享**——你在电脑上聊了一半，拿起手机可以继续聊同一个空间的对话历史、当前模型；但**三端视图独立**——手机 App 看到的是它自己当前盯着的空间，CLI / Web 各自也有自己的视图，互不镜像、互不拖拽。

## 17.2 怎么连上

连接需要三个角色就位：

1. **GoMatrix**：一个轻量 Matrix 服务器（纯 Go 实现的无头服务），负责在手机和电脑之间传消息。它由 coara 托管——本机 8008 端口已有健康实例时直接接入（adopt），否则自动拉起捆绑的 `gomatrix.exe`；拉不起来会跳过 Matrix
2. **电脑上的 coara**：常驻内核自动连接已运行的 GoMatrix（无需任何启动标志；`matrix.host_enabled` 默认开，配置不全时安静跳过）
3. **手机上的 coara App**：登录同一个 GoMatrix，进入同一个房间

具体步骤：

1. 启动常驻内核（`coara tray` 或裸 `coara`）——gomatrix 由 coara 托管自动拉起（无头服务）
2. 内核启动后自动登录、自动接受同域用户的房间邀请
3. 右键系统托盘图标 →「手机连接」，弹出配对二维码；手机 App 打开 设置 → 连接设置 → 扫码，扫屏幕上的配对码即完成配对——App 用配对凭据自动生成 `phone_xxxxxxxx` 账号并注册登录，无需手动输入凭据，之后就进入了和电脑同一个房间

GoMatrix 部署在局域网内即可，手机和电脑在同一个网络就能通；要在外网使用无需额外操作——gomatrix 默认自动拉起 Cloudflare 隧道，配对码编码的就是隧道地址（任意网络可用）。固定域名可用 named tunnel（WebUI 配置页 `matrix.tunnel_*`），App 里也支持手动输入服务器 URL。

消息可靠性方面有个细节值得知道：手机和电脑离线期间的消息不会丢。coara 用同步游标记住处理进度，重启后只补收新消息，不会把历史消息重新倒进对话。

## 17.3 手机上能干什么

不只是打字聊天。coara 运行中需要你做决定、或者有事要通知你时，手机端有对应的交互能力：

**审批与问答**
它要执行高风险操作（比如删文件、跑命令）时，手机上会收到一张**审批卡片**，点"同意/拒绝"，电脑上的工具调用随即继续或中止。你不在电脑前，审批不会卡住整个任务。

**宝箱解锁**
AI 需要开宝箱时，手机收到解锁卡片，输入主密码后电脑端开门。密码走专属侧信道，不进入 AI 对话上下文（和本地一致，见 [第 10 章 宝箱](./10-宝箱.md)）。

**工作空间动态红点**
各个工作空间有新动态（定时任务结果、工作流状态变化等）时，手机端工作空间菜单出现未读角标。点进去看详情，角标清零。推送走隐藏消息，不刷屏聊天界面。

**快捷面板**
长按输入框呼出面板：切换模型、切换工作空间、思考模式开关、新会话 / 中断 / 重启。面板里的选项列表是电脑端实时推下来的，看到的即是可用的。

**收发文件**
手机发图片/文件到房间，电脑端下载进当前工作空间；coara 要给你文件时（比如生成的 Excel），手机端直接收到可下载的附件。

**定时提醒**
电脑上设定的提醒到点时，会以高显著内容落当前活跃工作空间的动态收件箱，手机端经红点同步看到（不再单独弹房间消息）。

**输入交互**
输入栏上滑发送；附件按钮支持拍照、相册、文件；语音输入见下节。

## 17.4 语音输入

App 内置 SenseVoice 离线语音识别模型（INT8 量化，走 ONNX Runtime），**不依赖网络**：

- 点一次麦克风按钮开始录音（图标变为停止键），再点一次停止并识别出文字
- 识别结果插入到输入框**当前光标位置**，不覆盖已有文字——可以连续录几段再统一编辑发送
- 模型在首次使用麦克风时才加载，平时不占内存

## 17.5 两端状态如何保持一致

几个常见疑问：

**手机怎么知道当前在哪个工作空间？**
手机端有自己独立的"当前视图"（按房间 pin 绑定），入站消息路由到手机当前视图空间。你在电脑上 `/ws switch` 切换工作空间只改 CLI 的视图，手机不受影响；手机在快捷面板里也能切换工作空间，同样只切手机自己的视图——三端各看各的，互不拖拽。

**手机上审批了，电脑上会重复弹窗吗？**
不会。一个回合由哪一端发起，交互就走哪一端：远程回合的审批只在手机上出现，本地 CLI 不会重复弹。

**事件触发的自动回复，手机能收到吗？**
能。事件源、后台任务这类没有远程会话上下文的自动运行，Root 会通过通知桥把回复显式推送到房间——否则这些回复只在电脑屏幕上出现。

**聊天记录怎么显示？**
模型上下文在内核里是一份；**各端聊天界面**按发起端隔离（输出归属 = 最近一次注入端）：手机只显示手机发起的回合，Web 只显示 Web 发起的回合；CLI 会显示它端回合的收尾答复（带 `[Web]` / `[Matrix]` 前缀）方便盯场。回合中途切了工作空间，离开空间的回合在收尾时把最终答复投递回发起端，带空间名标记。手机不会把电脑上 CLI/Web 的闲聊刷进房间。App 本地缓存最近房间消息，用于快速打开。

## 17.6 进阶：协议是怎么工作的

给想了解内部机制的读者。

**remote_turn 上下文**
手机消息到达电脑后，适配器进入一个 `remote_turn` 上下文，登记房间号和一套交互接口（`RemoteInteractionChannel`：发文本、发选择题、发填空题、发确认）。Root 内部任何需要触达用户的地方，都通过这个接口找到当前远端，不关心底层是什么协议。未来接入别的远程渠道，实现同一接口即可。

**消息标签**
用户消息进入对话历史前按来源包上标签，让提示词系统知道这条消息来自哪一端：Matrix 来的包 `<手机消息>`，Web 来的包 `<web消息>`，CLI 来的不打标签。这些标签只存在于电脑端的对话历史里（供 LLM 读），Matrix 线上不传，落带前剥回裸文本。回合进行中你补发的消息包 `<接续输入>`；你在 App 里引用某条工作空间动态发问，则以 `<工作空间消息>` 引用协议传输。

**[COARA_*] 隐藏消息**
手机端的各种卡片和状态同步，走一类以 `[COARA_*]` 开头的特殊房间消息：

| 消息 | 用途 |
|------|------|
| `m.coara.approval` / `m.coara.approval_reply` / `m.coara.approval_resolved`（自定义 msgtype，非 `[COARA_*]` 文本） | 工具审批卡片、回执与终态 |
| `[COARA_VAULT]` / `[COARA_VAULT_REPLY]` | 宝箱解锁卡片与密码回执 |
| `[COARA_UPDATES]` | 工作空间未读动态角标 |
| `[COARA_MODELS]` / `[COARA_WORKSPACES]` / `[COARA_THINKING]` / `[COARA_USAGE]` / `[COARA_STATUS]` | slash 面板与工作空间浏览器的状态同步 |

这些消息在 Matrix 房间里真实传输，但 App 识别后不渲染进聊天列表——它们是控制面，不是对话。同样，手机发出的 `[COARA_*_REPLY]` 在电脑端被预过滤拦截，直接交给对应桥接模块，不进入 AI 对话。审批是例外：它走自定义 msgtype 的 `m.coara.approval*` 事件（content 即结构化 JSON），电脑端在 RoomMessageUnknown 事件层拦截并交 ApprovalCenter，同样不进入 AI 对话。密码、审批结果因此都不会出现在模型上下文里。

**后台保持在线**
App 不用厂商推送通道，靠 Matrix 长轮询 + 前台服务保持连接。开启"后台保持连接"后状态栏有常驻通知，退后台也能收消息和提醒；国产机型需要允许自启动并关闭电池优化。

## 17.7 本章小结

- 手机端是"遥控"：消息经 Matrix 中继给电脑上的常驻内核，AI 始终在电脑上运行
- 连接两步：启动常驻内核（gomatrix 托管自动拉起）→ App 扫系统托盘弹出的配对码登录同一房间
- 手机上可以：聊天、审批、答问、开宝箱、看动态红点、切模型/工作空间、收发文件、收定时提醒
- 语音输入用内置 SenseVoice 离线识别，按住说话、松开识别、插入光标处
- 上下文按工作空间共享、三端视图独立；审批、密码等敏感交互走 `[COARA_*]` 隐藏协议，不进 AI 上下文
