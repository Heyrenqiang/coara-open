# coara v8 系统运行说明书

一本从「coara 是怎么运转的」角度写的全景说明书。全中文、无代码，面向想彻底理解这套系统的读者——包括系统作者本人，以及需要"知道自己怎么工作"的 coara 自身。

阅读方法、术语约定见 [第 0 章 导读](./00-导读.md)；本页是目录。

---

## 从哪开始读

- **第一次接触 coara**：从 [第 1 章 系统总览](./01-系统总览.md) 开始，它用一页讲清 coara 是什么、怎么做事
- **刚装好要跑起来**：读 [第 2 章 启动与初始化](./02-启动与初始化.md)，配合 [第 19 章 配置系统](./19-配置系统.md) 填配置
- **只想查个命令或路径**：直接去 [附录 B 速查表](./B-速查表.md)
