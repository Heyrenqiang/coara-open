# 三端运行显示出站

> **Canonical**：屏幕上给人看的东西，先归类，再定投谁。  
> 对照：[三端入站](./三端入站.md) · [架构契约](./架构契约.md) · [消息渲染契约](./消息渲染契约.md) · [CLI_DISPLAY_FRAMEWORK](./CLI_DISPLAY_FRAMEWORK.md)

---

## 1. 三类（先认类）

| 类 | 是什么 | 投谁 | 出站规矩 |
|----|--------|------|----------|
| **Ⅰ 运行显示** | 回合在跑时盯着看的：正文、工具行、diff、活动树、Thinking、子智能体过程/结果、「后台 N 项」（**仅计数，不弹正文**） | **只到一个端** | **组帧当下**只投归属端；禁止先发全量再靠端上丢 |
| **Ⅱ 配置同步** | 模型 / 工作空间列表 / 用量 / 思考档等 chrome | 共看同空间的端可一起变 | 不是运行显示，允许跨端 |
| **Ⅲ 交互旁路** | 审批框、出站文件、slash 回执等 | **仍是发起端**（与下面「启动工具的端」同一归属，不是第三把尺） | 走定向通道（弹窗/文件桥），形态不是时间线运行态 |

落带存档 ≠ 显示：磁带可全端进线；**Ⅰ 的实时出站**不得借「落带读端过滤」开先例。

---

## 2. 归属只有两把尺（Ⅰ 与 Ⅲ 共用）

认完类别之后，投谁只看：

| 尺 | 跟谁 | 用在哪 |
|----|------|--------|
| **当前段** | 谁最后往会话里注入，后续主会话产出跟谁 | 正文、主会话工具行/diff、回合 Thinking/活动树主干 |
| **启动／发起端** | 谁触发了这件事（调 `delegate`、开后台、点出审批/发文件的那一端）；钉死不跟后来跟话易主 | 子智能体过程与结果、后台运行中与完成、Ⅲ 的审批/文件 |

代码里 `_subagent_origin`、`origin_source`、交互通道上的发起端——**都是这第二把尺**，只是字段名不同。

Ⅲ 相对 Ⅰ：差在**画成什么、走哪条管子**（旁路 UI vs 时间线），**不**差在「另有一套归属」。

---

## 2.1 注入信封永不上屏（09-25 裁决）

- **后台任务 / 子智能体结果永不上屏**：结果与完成提示若以注入信封形态存在（`is_preformatted_injection` 判真），三端一律不上屏；**Ⅰ** 里只保留「后台 N 项」这类计数与 trace 层摘要，端上不弹正文。
- **子智能体内容只折进 delegate 工具行**：过程正文与最终结果（帧 kind `subagent_chunk` / `subagent_result`）三端一致折进发起它的 delegate 工具行，绝不进主消息流。回归：`tests/test_ui/test_subagent_frame_leak_guard.py`。

## 3. 改动自检（三问）

1. 属于 Ⅰ / Ⅱ / Ⅲ 哪一类？  
2. 若不是 Ⅱ：用「当前段」还是「启动／发起端」？  
3. 组帧时是否已经只投该端？（「先推再滤」→ 不许合）

---

## 4. 与代码对照

| 类 · 尺 | 原则 | 现状 |
|---------|------|------|
| Ⅰ · 当前段 | EndRegistry 按段投一端 | **符合** |
| Ⅰ · 启动／发起端（子智能体） | 派发快照投一端 | **符合** |
| Ⅰ · 启动／发起端（后台 trace / Web 计数） | 只进该端 | **符合**（`snapshot_running_tasks(origin_end=…)`） |
| Ⅰ · 启动／发起端（CLI「后台 N 项」） | 只进该端 | **符合**（attach 心跳 / spinner 均按 CLI 族出站） |
| Ⅰ · 注入信封 | 后台任务 / 子智能体结果不上屏 | **符合**（三端显示出口统一按 `is_preformatted_injection` 拦；回归 `tests/test_ui/test_subagent_frame_leak_guard.py`） |
| Ⅱ | 可跨端 | 另路径 |
| Ⅲ · 启动／发起端 | 定向到该端 | 另通道，归属同尺 |
