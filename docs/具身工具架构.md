# 具身工具架构（coara 有手有嘴，自拍手机拍下它）

> **一言以蔽之**：coara 不是"做视频的工具"，而是一个**具身智能体**——它拥有手、嘴巴、字这些「器官」，在真实环境（上下文 + 桌面）里自导自演；一台「外部手机」旁观地把它的真实行为旅程被动捕捉下来。
> **状态**：核心器官已落地（2026-08-22）。这是整个「自导自演」方向的架构总纲，取代此前"录屏→后期配音→后期字幕→合成"的后期制作思路。voice/subtitle 实时器官、可录性验证、技能重写均已完成（见 §8）。
> **关联**：`docs/task_led_自导自演.md`（task-led 流程）、`skills/self_demo`（行为指导）、`standalone/makevideo`（录制引擎）。

## 1. 核心隐喻：三层分工

**外部手机（自拍镜头）= 录制工具**，在 coara 之外

- 只被动捕捉，不是 coara 的器官
- 相当于「别人拿手机拍我」

**coara 的具身器官**（嵌入 coara，实时做事）

- 手 = actuate（键鼠、滚屏、点击、输入）
- 嘴巴 = voice（实时发声，被手机录进）
- 字 = subtitle（实时烧字，被手机录进）
- 行为真实发生，被外部手机被动捕捉

**环境 = 上下文**

- coara 的 LLM = 大脑，读环境、做判断
- 调用具身器官，模拟手+嘴巴，在环境里自导自演

- **大脑**：coara 的 LLM。读环境（上下文），做判断，指挥器官。
- **器官**：手（actuate）/ 嘴巴（voice）/ 字（subtitle）。调用即真实发生。
- **环境**：上下文 + 真实桌面。coara 在环境里真实行动。
- **手机**：录制工具。旁观者，被动捕捉真实行为旅程。

## 2. 关键转变：从「后期制作」到「实时具身行为」

这是整个方向的一次根本切换：

| 维度 | 旧：后期制作 | 新：实时具身 |
|------|-------------|-------------|
| 流程 | 录屏 → 后期配音 → 后期字幕 → 合成 | coara 边做、边说话、边打字，被实时录 |
| 声音 | 后期用 TTS 生成音频再配 | **voice 工具调用 = 当下真发声**，被手机录进 |
| 字幕 | 后期按时间轴烧 | **subtitle 工具调用 = 当下真烧字**，被手机录进 |
| 操作 | 预设脚本键鼠 | **actuate 实时操作**，真实发生 |
| 同步 | 靠后期对轨（易错） | **天然同步**——因为它们同一时刻真实发生，不是拼的 |
| 类比 | 拍电影（拍完剪辑） | **直播 / 录课**（当下真实表演） |

**核心**：不再"记录一个静默画面再加工"，而是"coara 用器官在真实环境里表演，手机把它真实的行为旅程捕捉下来"。声音、字幕、操作都是**当下用器官完成的真实行为**，不是后期合成。

## 3. 具身器官（coara 要嵌入的能力）

这些是**器官级能力**，coara 随时可调用，行为实时发生：

| 器官 | 工具 | 调用后的真实行为 | 嵌入方式 |
|------|------|----------------|---------|
| 手 | `embody` 的 `actuate` | 键鼠移动/点击/滚屏/输入（真实操作桌面） | coara 挂起工具，直调直出效果（owner_only） |
| 嘴巴 | `embody` 的 `voice` | **在电脑上真正放声**（被麦克风/系统录音捕获） | 同上；`wait=false` 可后台讲（边说边做） |
| 字 | `voice` 的 `caption` 参数 | **实时在屏幕上输出字幕**（被录进画面） | 非独立器官：讲一句话 = 放声+同文烧字，说完即隐；`caption=false` 关闭 |

**关键区别**（vs 旧的 make_video 封装）：
- 旧 `voice` 生成的是**音频文件**（后期才用）
- 新 `voice` 是**实时发声工具**——调用就在电脑上放出声音，手机/录音能实时捕捉
- 旧 `subtitle` 生成 `.srt`（后期烧）
- 新 `subtitle` 是**实时烧字工具**——调用即把字显示到屏幕，被录进

**所以语音同声、字幕同步天然成立**——因为它们和操作是同一时刻用器官一起完成的真实行为。

## 4. 录制工具 = 外部手机（不是 coara 器官）

- **定位**：在 coara 之外，独立存在（如 `standalone/makevideo` 引擎）。
- **职责**：被动捕捉。start（架好手机）/ stop（收起）。
- **不参与表演**：它只是拍，拍什么取决于 coara 器官在环境里做了什么。
- 不加工、不对轨、不合成——**合成/加工是后期思路，已废弃**。手机拍的就是原片。

## 5. 流程（coara 视角：自导自演）

1. **接收指令**：用户「录一个 X 演示」。
2. **架手机**：coara 开录制（`screenshot` 工具 `record_start`）——外部手机开始被动捕捉。
3. **大脑读环境**：coara 从上下文理解任务，拆解成步骤。
4. **用器官表演**：对每一步——
   - **手** `actuate`：真实操作（点、输、滚）
   - **嘴巴** `voice`：当下讲话（"这一步我在……"），同文字幕同步上屏（caption 协同）→ 手机录进
   - 边做边说边打字，行为真实、同步天然
5. **随时判断**：大脑读环境反馈，调整下一步（像真人一样应变）。
6. **收手机**：`record stop`（`screenshot` 工具 `record_stop`），拿到真实行为旅程的原片。

## 6. 对 self_demo 技能的意义

`self_demo` 技能承载的是**「coara 如何像人一样演示」的行为指导**（见 `skills/self_demo`），核心是身份切换：从"执行任务"到"向观众讲解的叙事者"。

具身架构让这个身份**第一次真正可落地**——因为 coara 现在真的有手可指、有嘴可讲、有字可打，能像真人一样边做边说边演，而不是后期拼。

## 7. 回看此前实现：哪些保留 / 哪些废弃

| 组件 | 状态 | 说明 |
|------|------|------|
| `standalone/makevideo` 引擎 | 保留（作为「外部手机」） | 录屏 start/stop，被动捕捉。engine 内核 |
| `standalone/makevideo` 的 voice/subtitle | **已改造** | 旧的"生成音频/字幕文件"（后期）已拆除，改成"实时发声/实时烧字"的器官级工具 |
| `makevideo` 封装 CLI | 保留 | actuate/voice/subtitle/mark 器官经 CLI 调用；record 进 coara `screenshot` 截屏套工具（单帧/连续捕捉同族，工作空间自动绑定） |
| `voice` / `subtitle` 具身工具 | **已落地** | coara 挂起工具 `embody`（actuate/voice/mark）；字幕并入 voice 的 caption 参数（声字协同，引擎 `narrate.py`）；CLI `python -m makevideo` 保留作备用/worker |
| `self_demo` 技能 | 保留（行为指导） | 教 coara 如何用这些器官像人一样演示，第三章已按具身架构重写 |
| `task_led_自导自演.md` | 保留 | task-led 流程；已对齐本架构 |
