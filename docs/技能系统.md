# 技能系统（Skills）

> 技能是**面向 LLM 的运行时指令**（一份任务领域指南），不是可执行代码插件。
> Root 侧使用规范文案在 `src/coara/prompts/agents/root.md` §技能使用规范；缓存约束见 [`PROMPT_CACHE_POLICY.md`](./PROMPT_CACHE_POLICY.md)。

## 1. 一张图

```text
磁盘（人维护）                        运行时（LLM / Root）
─────────────────                    ──────────────────────────────
skills/（出厂默认，程序目录）  ┐
<coara_home>/users/default/skills/  ├─► discover → 技能池（SkillManager）
<workspace>/.coara/skills/  ┘            │
  每目录一个 SKILL.md                     ├─ skill(action=search)   → 按关键词查 name + description
  增删 = 放/删目录                        ├─ skill(action=activate) → 完整 SKILL.md → message_history
                                          └─ skill(action=import)   → 从其它空间整份复制进本空间
```

**System prompt 只注入技能名清单**（root.md 的 `${COARA_SKILL_LIST}` 占位符，启动时发现、会话内静态；配置 `skills.deferred` 名单内的技能不进清单，只能经 `skill(action=search)` 发现）。会话内要忘掉已加载的指南 → `/new`。

## 2. 磁盘：增删技能

### 目录约定

```text
my-skill/
├── SKILL.md       # 必需：YAML frontmatter（name, description）+ 正文指南
├── references/    # 可选
└── scripts/       # 可选
```

frontmatter 的 `name`、`description` 必填，缺了该技能加载失败（记 warning 跳过）。`name` 保留 Unicode 词字符（中文名原样保留）、下划线、连字符，其他字符**逐个替换为 `_`**。挂起与否不写进 SKILL.md——由配置 `skills.deferred` 名单决定（唯一真相，配置页「技能」区有开关，改动新会话生效）；名单内的技能不进 system prompt 的技能名清单，只能靠 `skill(action=search)` 发现。

### 发现来源（`SkillManager.discover()`，同名后者覆盖前者）

| 顺序 | 路径 | 级别 |
|------|------|------|
| 1 | 仓库 `skills/` | 全局级（出厂默认，程序目录只读，在线保存被拒） |
| 2 | `<coara_home>/users/default/skills/` | 全局级（对所有空间生效，可覆盖出厂同名） |
| 3 | `<workspace>/.coara/skills/` | 工作空间级（目录存在即加载） |
| 4 | 运行时 `extra_paths` | 扩展 |

体系只有两级：**全局级**（所有空间可见，出厂技能与用户自加的都在这层，同名时用户目录覆盖出厂）与**工作空间级**（跟空间走）。出厂技能只读——要改就在全局级目录放同名副本，升级不冲用户改动。

加载器对每个来源目录递归查找 `SKILL.md`（`rglob`）。

| 操作 | 做法 |
|------|------|
| 添加 | 新建目录 + `SKILL.md` → `/new` 或重启 coara 后生效 |
| 删除 | 删目录 |
| 修改 | 改磁盘文件；history 里已 activate 的旧正文不会自动更新，需 `/new` 后重新 activate |

`/new` 时会重新加载配置并重新 `discover()`（`src/coara/base.py` 的 `start_new_session` 流程），所以增删技能不需要重启进程。

编写规范见 `skills/skill-creator/SKILL.md`。

## 3. 运行时：`skill` 工具

仅 **Root**（`owner_only`）。三个 action，**没有 add/remove**——磁盘增删见上节。

| action | 作用 | 改会话状态 |
|--------|------|------------|
| `search` | 按关键词查找（只看不用）；query 留空返回全量；scope=current（默认）查当前可用链，scope=all 另列其它空间的技能并标注来源空间 | 否 |
| `activate` | 把完整 SKILL.md 以 `<系统提醒>` + `<activated_skill>` 形式写进 history；只能 activate 当前链上的技能 | 是 |
| `import` | 把其它空间的技能整份**复制**（非引用）到当前空间 `.coara/skills/`，复制后即可 activate；name + from_workspace 必填，同名冲突默认拒绝（overwrite=true 覆盖）；已在当前链上的同名技能拒绝搬运；副本落 `.imported-from` 来源注记 | 否（写磁盘） |

跨空间搬运流程：`skill(action="search", scope="all", query=…)` 找到来源空间 → `skill(action="import", name=…, from_workspace=…)` → `activate`。复制即分叉：源技能后续更新不会同步到副本。

推荐流程（每步仅在本会话尚未完成时执行）：

1. `skill(action="search")`
2. 选最匹配的技能
3. `skill(action="activate", name=…)`

search 输出里的标记：

- `挂起` — 在配置 `skills.deferred` 名单内，不进 system prompt 技能名清单，只能靠 search 发现再 activate
- `activated` — 本会话已 activate

`activate` 的内部行为（`src/skills/activation.py`）：

- 名字不存在 → 返回 error 并附上可用技能清单；
- 成功 → 技能名加入 `SkillSessionState.activated`，content 为 `<activated_skill name=…>`（含正文、磁盘路径、可选 references 列表）；
- `workflow` 技能额外置 `_workflow_draft_pending`：本 turn 内若 LLM 没成功调 `orchestrator(action="save/run")` 就想结束，turn 循环会注入续跑提醒。

`SkillSessionState`（`src/skills/session.py`）只记 `activated: set[str]`，`/new` 时 `clear()`。

## 4. 推荐配置（可选）

```yaml
# config.yaml
skills:
  default_include: []   # Dashboard 推荐勾选（/api/v1/skills）
  default_exclude: []
```

推荐标记（现行实现）：Dashboard / `/api/v1/skills` **直读** `config.yaml` 的 `skills.default_include`（`["*"]` 表示全选）算出推荐集合；agent YAML 的 `skills.include` / `skills.exclude` 是另一用途（决定该 agent 装载哪些技能，见 `src/prompt/yaml_loader.py`），不参与该推荐标记。这套配置**只决定 Dashboard 推荐勾选**，不改变 discover 结果，`skill(action=search)` 也不输出 default 标记。

## 5. Root 规范（摘要）

见 `root.md` §技能使用规范：

- 领域任务优先用技能完成，不凭通用经验直接做；
- 不确定用哪个技能时先 `skill(action="search")` 查候选，确定后 `skill(action="activate", name=…)` 加载（name 取唯一技能名）；
- 已加载过则无需重复；加载的技能必须严格遵照执行。

## 6. 出厂技能（仓库 `skills/`）

| 目录 | 用途一句话 |
|------|-----------|
| `event-source` | 事件源配置（kind / salience / handle / 模板；规格见同目录 EVENT_SOURCE_SPEC） |
| `工作空间管理` | coara Home 侧配置与工作空间运维 |
| `skill-creator` | 怎么写新技能 |
| `tool-creator` | 怎么写磁盘工具包 |
| `create-rule` | 编写 `ws.md` / `AGENTS.md` / `user_rules.md` |

编排用挂起工具 `orchestrator`（`tool(activate)`）；图/视频用内置 `media`。

以运行时 `skill(action="search")` 为准。
