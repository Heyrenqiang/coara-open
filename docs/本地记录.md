# 本地记录（records）

> **Canonical**：本地记录的产品模型与接线真相。历史设计长文已归档（`ref-doc/archive/`），冲突以本文为准。

## 1. 一句话

两层：**agent 情境笔记** vs **用户文件库（收藏为主，手点）**。

| origin | 含义 | 谁写入 | 磁盘 |
|--------|------|--------|------|
| `agent` | 情境笔记 | 仅 **janitor / daily** 的 `record` 工具 | `records/agent/` |
| `user` | 用户收藏（**文件为主**） | **人手点**：Web 文件页收藏、记录页按钮、手机消息卡片；**无** CLI slash、**无** LLM 代写 | `records/user/` |

**主会话（Root）**：不挂 `record`；只挂延迟加载的 `local_search`。用户口头说「收藏」不要代写——等端上手点。

## 2. 工具与人侧入口

| 面 | 名称 | 职责 |
|----|------|------|
| LLM 写 | `record` | `add` / `update` / `remove` / `archive` / `unarchive` / `digest_write`（仅 agent；仅 janitor/daily）；开关 = 配置 `records.enabled` |
| LLM 读 | `local_search` | `search` / `list` / `show` / `source`（录像带回放）；`origin=all\|agent\|user` |
| CLI | （无） | `/records`、`/collect` 已退役 |
| Web | 文件页「收藏」+ 记录页 + `POST /api/records/collect(-file)` | 手点写 user；浏览 agent |
| 手机 | 消息卡片「收藏」 | Matrix `[COARA_COLLECT]` → PC `records/user/` |

## 3. 存储与模块

```text
<coara_home>/users/default/records/
  agent/     # 类型目录、digests、archive、index、curator_state
  user/
    entries/ # *.md 索引正文
    files/   # <entry_id>/ 原件（文件收藏）
    index.yaml
```

| 层 | 路径 | 作用 |
|----|------|------|
| 统一 store | `src/records/store.py` | `RecordsStore`：`agent` + `user` 子树 |
| 门面 | `src/records/facade.py` | 工具 / Web / Matrix collect 共用写读 API |
| LLM 工具 | `src/tools/builtin/records/` | `record`、`local_search` |
| 手机旁路 | `src/matrix_client/collect_bridge.py` | `[COARA_COLLECT]` |

配置：`records.enabled` / `default_ttl_days` / `daily_curator_enabled` / `curator_timezone`（见 `docs/CONFIGURATION.md`）。

## 4. 生命周期

```text
用户对话 ──空闲超时──► janitor → ws.md + record(agent)
日历清晨 ────────────► daily → 近 7 天 agent 记录维护 + digest + 轮播语
人 ──Web 文件收藏 | 记录页 | 手机卡片──► origin=user（不经 LLM）
```

## 5. 安全

- agent 写入：`src/records/agent_gate.py`（拒密钥等）
- user 收藏：拒明显密钥模式

## 6. 明确不做（当前）

- 向量检索
- 主会话 / janitor LLM 代写收藏
- CLI `/records` / `/collect`
- 手机本地存原件（原件只在 PC `records/user/files/`）
