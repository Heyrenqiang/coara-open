# 系统术语表

全系统概念与名词的统一词典。改某个地方之前先在这里对号入座，用正式术语描述位置，避免「那个页」「转圈那行」这类指代。

## 使用与维护约定

- 每条格式：术语名 — 一句话定义 ｜锚点: `文件:符号` ｜别名: 用户可能的口头说法
- 查法：先按 端 定位大章（CLI / Web / Android 与 Matrix / 核心内核），再按 域 定位小节；拿不准时搜别名
- 新增功能落地时，顺手把新概念补进对应小节；改名时同步改这里，别名里保留旧叫法一段时间
- 锚点给的是代码定位线索（文件+关键符号），不保证行号精确，以符号名为准
- 状态：v1 初版，2026-08-24 盘点生成

## 动态提示区（spinner 区）

- **唯一 spinner 行** — 输入框上方常驻的那一行动态状态，整合 Thinking 动画、计时与后台空间段，全终端只有这一行在转 ｜锚点: `src/cli/spinner.py:BackgroundSpinner.__call__` ｜别名: 转圈那行、状态行

- **轮播语（轮换短语）** — Thinking 行上每 30 秒换一条的幽默梗/名言/小技巧文案；daily 每日还会写一批定制轮播语整池替代 ｜锚点: `src/records/loading_phrases.py:current_phrase`、`loading_phrases.json`、`loading_phrases_custom.json` ｜别名: 轮换文案、加载语、俏皮话

# 五、易混术语消歧

- **主会话** = foreground_coara（agent_kind=root，用户直面的前台会话）
- **任务会话**（口误）→ 多数指 子智能体会话（delegate spawn 出的 coaras/aide 等），少数语境指 后台回合（主会话里事件驱动的后台 turn），说的时候建议直接用正式名
- **llm 调用页** = 独立开发者工具 coara-devtools（读 `.coara/llm/llm-calls.jsonl` 磁盘镜像），非发布版 Web/Android 页面
- **记录页的显示** = 记录页（RecordsView）右侧 记录详情面板，正文 MarkdownMessage 渲染
- **手机端侧边栏的消息模块** = Android 抽屉里的 消息页（ReviewScreen），与 Web 端 消息页（ReviewView）同源
- **消息页**（Web /review 与 Android ReviewScreen）vs **消息列表**（Web 对话页的 MessageList）：前者是工作空间动态收件箱，后者是聊天消息流
- **记录 vs 收藏**：agent 记录（MemoryStore，智能体自动写）与 user 收藏（CollectionStore，用户明示收藏）是 records 下两棵子树
- **日报 vs 记录**：日报是 daily 每天写的 digest（digests/YYYY-MM-DD.md），记录是 janitor/daily 日常维护的条目
- **轮播语**：内置词库 loading_phrases.json（witty+quotes 两池）与 daily 定制 loading_phrases_custom.json（存在即整池替代）
